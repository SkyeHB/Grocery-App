# Workflow

1. Create & switch to your feature branch from the updated development branch
2. Write your code in the newly created branch
3. Create a pull request to the development branch
4. At least two people will review and unanimously approve the pull request (no testing is done, accepted as good faith code by the developer)
5. The code is merged to the development branch
6. At the end of the sprint the branch is pulled to main
7. The team begins testing the system noting errors
