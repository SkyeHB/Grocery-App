# Working agreement 

## Communication 

1. We expect members to check Discord or Teams at least once a day and get back with any question posed to them. 
2. Members are not expected to respond to messages posed to them after 5 pm on the same day.
3. All members are expected to attend the meeting on Friday starting at 4pm with the meeting running at most to 6pm. 
4. All members should have equal say on how the project should evolve and change.
5. Members are expected to be polite to each other.

## Coding standards

1. All Members should contribute changes to the [Github repository](https://github.com/CAPSTONE-2022-2023/Group_23).
2. Members should minimize defects and bugs in the code they submit.
3. Members have equal right to edit any code in the repository.
3. Members are expected to follow and maintain the [Mozilla Code Style Guidelines](https://developer.mozilla.org/en-US/docs/MDN/Writing_guidelines/Writing_style_guide/Code_style_guide/JavaScript).
4. Members should develop a familiarity with [Angular](https://angular.io/start), [Node.js/Express](https://expressjs.com/en/starter/installing.html) and [Postgress SQL](https://www.postgresql.org/files/documentation/pdf/14/postgresql-14-US.pdf).


## Consequences

If members break the [Communication](#communication) or [Coding standards](#coding-standards) it be will addressed during the following group meeting to better understand the issue and try to accommodate that member. 
If the group member continues the behaviour and it appears to be done maliciously then the issue will be brought up to Marcel
