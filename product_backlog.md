# Product backlog

Form: As a [persona], I [want to], [so that]

## General user
- As a user I want to be able to login to the store so that I can access my account

## Shopper
- As a shopper I want to be able to view the featured products so that I can find new products and deals
- As a shopper I want to know basic information about the store so that I can find the location and operating hours
- As a shopper I want to a robust product page which lists products so that I can view most up to date information about the products
- As a shopper I want to quickly search and filter products so that I can find products I'm looking for easier
- As a shopper I want to create an account so that I can save my shopping preferences
- As a shopper I want to save items I'm buying to a cart so that I can purchase them at the same time
- As a shopper I want to be able to have my products delivered to me so that I can save on travel time
- As a shopper I want to be able to pick up products so that I can save on delivery fees
- As a shopper I want to purchase my products using a credit card so that I can purchase the products over the internet
- As a shopper I want to pick the time of delivery so that I can receive products when I want

## Store owner
- As a store owner I want to update and add products to the stores catalogue so that shoppers can find new products and their updated information.
- As a store owner I want to be able to see incoming orders so that I can service the orders
- As a store owner I want to have a dashboard that allows me to change my store settings so that I can customize my shoppers experience
- As a store owner I want to see a list of users for my store so that I can view data about their past purchases
- As a store owner I want to be able to search for users on my store so that I'm able to find users
- As a store owner I want to be able to search transaction history so that I know what my users are buying
