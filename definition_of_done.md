# Definition of done

1. The code and functionality meets its specific acceptance criteria.
2. The code compiles and runs on the writer's end.
3. The code is pushed to a working branch and is downloadable by all members.
4. The code is tested by at least one member who didn't write it and no issues are found.
5. A pull request to merge the code to the main branch is created and passes all GitHub checks.
6. The pull request is reviewed and merged by a member who tested but didn't write the code.
7. The updated program and functionality passes an acceptance test on the public server.
